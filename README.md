# מכינת נהריה — מערכת ניהול

חניכים, הורים, נוכחות והודעות בוואטסאפ. עובד מהמחשב ומהטלפון (אפשר להתקין כאייקון).
רק אנשי צוות שהמנהל הוסיף רואים משהו — זה נאכף במסד הנתונים (RLS), לא רק במסך.

## איפה מה

| קובץ | מה יש בו |
|---|---|
| `docs/` | כל האתר — זה מה שעולה לאינטרנט |
| `docs/config.js` | כתובת Supabase + המפתח הציבורי (publishable). **אף פעם לא מפתח secret / service_role** |
| `docs/app.js` | המסכים: בית, חניכים, כרטיס חניך, טופס, נוכחות, הודעות, הגדרות |
| `docs/logic.js` | חישובים: טלפונים, ימי הולדת, חיסורים ברצף, אחוז נוכחות, ייצוא לאקסל |
| `docs/monitor.js` | ניטור תקלות → הגדרות → "תקלות טכניות" (רק למנהל) |
| `supabase/schema.sql` | מסד הנתונים + האבטחה. מריצים פעם אחת ב-SQL Editor |
| `tests/logic.test.js` | בדיקות לחישובים: `node --test tests/logic.test.js` |
| `tools/` | כלי בדיקה מקומיים (serve.py, sitecheck.py) |

## אוטומציות שקורות לבד (בדף הבית)

- 3 חיסורים ברצף → התראה + כפתור הודעה מוכנה להורה
- ימי הולדת ב-7 הימים הקרובים → כפתור מזל טוב
- נוכחות היום לא הושלמה (א׳–ה׳)
- חניכים בלי טלפון תקין של הורה
- תקלות טכניות ב-24 שעות (למנהל)

## הוספת איש צוות

1. Supabase → Authentication → Users → **Add user** → Create new user → מייל + סיסמה → לסמן **Auto Confirm User**.
2. במערכת: הגדרות → צוות → מייל + שם → **הוספה לצוות**.

## מגבלות ידועות

- הודעות וואטסאפ נשלחות אחת-אחת (לחיצה לכל הורה). שליחה אוטומטית המונית דורשת שירות בתשלום.
- נוכחות: שורה אחת לחניך ליום (לא לפי פעילות/שיעור).
- Supabase החינמי נכנס ל"שינה" אחרי 7 ימים בלי שימוש בכלל — בשימוש יומי זה לא קורה. אם קרה: נכנסים ל-Supabase ולוחצים Restore.
- Supabase החינמי לא עושה גיבויים — לכן יש ייצוא לאקסל בהגדרות. מומלץ פעם בשבוע.
